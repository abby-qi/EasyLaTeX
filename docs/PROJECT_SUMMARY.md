# EasyLaTeX 项目总结文档

## 项目概述

**项目名称**: EasyLaTeX - 极简可视化LaTeX编辑器
**项目类型**: 桌面应用程序（Electron + Vue + Python）
**开发周期**: 2026-01-09 至 2026-01-09
**项目状态**: MVP完成，准备发布v0.1.0

---

## 项目目标

为不懂LaTeX的用户（研究生、中小学老师等）提供Word式可视化操作，零配置生成学术PDF。

### 核心价值主张

1. **零学习成本**: 用户无需学习LaTeX语法，通过点击按钮即可插入公式符号
2. **专业输出**: 自动生成符合学术标准的PDF文档
3. **跨平台**: 支持Windows、macOS和Linux
4. **开源自用**: 基于MIT许可证，完全开源

---

## 技术架构

### 整体架构

```
┌─────────────────────────────────────────────────┐
│           Electron 主进程                │
│  (main/index.js)                      │
└──────────────┬──────────────────────────┘
               │ IPC通信
               ▼
┌─────────────────────────────────────────────────┐
│         Vue 3 前端渲染进程             │
│  (frontend/components/, pages/)             │
└──────────────┬──────────────────────────┘
               │ HTTP请求
               ▼
┌─────────────────────────────────────────────────┐
│         Python 后端服务                 │
│  (backend/latex_generator/,              │
│   compiler/, exporter/, utils/)           │
└─────────────────────────────────────────────────┘
```

### 技术选型

#### 前端技术栈

| 技术 | 版本 | 用途 | 选型理由 |
|------|--------|------|----------|
| Electron | 28.0.0 | 跨平台桌面应用 | 成熟稳定，生态完善 |
| Vue.js | 3.x | 渐进式UI框架 | 学习曲线低，性能优秀 |
| Node.js | 18+ | JavaScript运行时 | Electron依赖 |

#### 后端技术栈

| 技术 | 版本 | 用途 | 选型理由 |
|------|--------|------|----------|
| Python | 3.9+ | 后端逻辑 | 生态丰富，易于维护 |
| pylatex | 1.4.2 | LaTeX代码生成 | 功能完整，文档清晰 |
| python-docx | 1.1.0 | Word文档导出 | 简单易用，支持中文 |
| subprocess32 | 3.5.4 | 进程管理 | Windows兼容性 |

#### 构建和部署

| 技术 | 用途 | 选型理由 |
|------|------|----------|
| Docker | 容器化部署 | 环境一致，易于分发 |
| electron-builder | 多平台打包 | 支持Windows/macOS/Linux |
