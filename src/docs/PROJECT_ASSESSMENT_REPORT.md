### 6.1 当前问题

由于 Node.js 环境变量未正确配置,无法直接运行 `npm start`。

### 6.2 解决方案

#### 方案1: 使用完整路径(临时)
```powershell
cd d:\Code_File\EasyLaTeX
"C:\Program Files\nodejs\npm.cmd" install
"C:\Program Files\nodejs\node.exe" "C:\Program Files\nodejs\node_modules\electron\cli.js" .
```

#### 方案2: 永久配置环境变量
```powershell
# 以管理员身份运行 PowerShell
[System.Environment]::SetEnvironmentVariable("Path", $env:Path + ";C:\Program Files\nodejs", "User")
# 重启 PowerShell
```

#### 方案3: 重启系统
winget 安装后重启系统可自动配置 PATH。

### 6.3 标准启动流程

```bash
# 1. 安装前端依赖
npm install

# 2. 启动应用
npm start

# 3. 开发模式
npm run dev
```
