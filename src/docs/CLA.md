您保证：
- 您有权签署本协议并转让上述权利
- 您的贡献是原创的，且未侵犯任何第三方的知识产权
- 您的贡献可以在 AGPLv3 下合法发布

## 3. 签署方式

### 3.1 个人贡献者

个人贡献者可以通过以下方式签署本协议：
1. 在您的首次 Pull Request 中，添加一条评论：
   ```
   I hereby agree to the terms of the Contributor License Agreement.
   ```

### 3.2 企业贡献者

如果您代表企业或组织做出贡献，您需要：
1. 确保您有权代表该企业或组织签署本协议
2. 在您的首次 Pull Request 中，添加一条评论，明确指明您代表的企业或组织：
   ```
   I hereby agree to the terms of the Contributor License Agreement on behalf of [公司/组织名称].
   ```

本协议自您签署之日起生效，并适用于您对 EasyLaTeX 项目的所有贡献，无论贡献的形式如何（包括但不限于代码、文档、bug 报告、功能请求等）。
